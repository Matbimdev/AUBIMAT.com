# AUBIMAT

**AUBIMAT** is a productivity add-in for **Autodesk Revit (2022–2026)** that automates
architectural, structural and MEP BIM tasks — ceilings and floors from walls, CAD-to-Revit
conversion, clash detection, QA fixes and more.

🌐 **Website:** https://aubimat.com

This repository hosts the AUBIMAT website.
